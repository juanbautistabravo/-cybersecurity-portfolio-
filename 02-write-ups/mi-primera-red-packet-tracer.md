# Mi primer portfolio de ciberseguridad en GitHub

**Fecha:** 20/09/2026
**Categoría:** Herramientas / Portfolio
**Nivel:** Básico

---

## 1. Objetivo

Armar desde cero un portfolio de ciberseguridad en GitHub, usando solamente la versión web, para documentar mi aprendizaje y mis proyectos a medida que avanzo.

## 2. Entorno y herramientas

- Software: GitHub (versión web) y navegador
- Formato de escritura: Markdown
- Fuente del laboratorio: propia

## 3. Pasos realizados

1. **Creé un repositorio público** llamado `cybersecurity-portfolio` con un archivo README.
2. **Definí la estructura de carpetas:** `01-networking-labs`, `02-write-ups`, `03-risk-assessment`, `04-policies` y `study-log`. Como GitHub no guarda carpetas vacías, cada una se crea junto con un archivo `README.md` adentro.
3. **Edité el README principal** con mi presentación, en español y en inglés, mis cursos y la lista de carpetas del portfolio.
4. **Revisé el formato con la pestaña Preview** antes de guardar, y guardé cada cambio con **Commit changes**.

## 4. Resultados

El repositorio quedó organizado, con las carpetas visibles en la lista y el README con formato debajo de ella. GitHub muestra primero las carpetas y después los archivos, en orden alfabético, por eso el README aparece al final de la lista.

## 5. Qué aprendí

- **Cómo se organiza un repositorio:** carpetas y archivos van al mismo nivel. El README es un archivo más, y las carpetas no van dentro de él.
- **Qué es Markdown:** un formato simple donde símbolos como `#` (títulos), `**` (negrita) y `-` (listas) se convierten en texto con formato.
- **Qué es un commit:** guardar un cambio dejando registro de qué se modificó y cuándo. Esa trazabilidad es un principio importante en seguridad.
- **Que GitHub guarda el historial:** si borro algo por error, puedo recuperar versiones anteriores desde **History**.
- **Qué no se debe publicar:** contraseñas, claves ni datos reales de pacientes. Todo el material de mi portfolio usa datos ficticios.

## 6. Errores que tuve y cómo los resolví

- **El README se duplicó** varias veces al copiar y pegar. Lo resolví borrando todo el contenido del archivo con Ctrl+A y Delete, pegando una sola vez y revisando en Preview antes de guardar.
- **No encontraba el botón "Add file" dentro de una carpeta.** Lo resolví creando el archivo desde la página principal del repositorio, escribiendo la ruta completa en el nombre, por ejemplo `02-write-ups/nombre-del-archivo.md`.
- **Borré contenido por error** mientras editaba. Aprendí a cancelar los cambios no guardados y a recuperar versiones anteriores desde el historial.
